May 18, 2024 — Planning Note: Component Architecture for Loam Luxury

Drawing from the modular showcase structures on Behance and CollectUI's UI patterns, Loam Luxury requires a component architecture that balances editorial flexibility with heavy WebGL/media performance. The system must decouple visual flair from DOM structure while maintaining rigid layout controls.

Key Structural Components & Technical Patterns:

* **Dual-Layer Stage Architecture (`<ViewportStage>` vs. `<EditorialDOM>`):** Decouple WebGL/Canvas rendering from DOM layout. Create a global canvas layer synchronized with standard DOM nodes via a unified React Context (`CanvasRegistry`). DOM elements like `<ShowcaseCard>` publish their viewport bounding boxes (`getBoundingClientRect`) to the canvas, allowing dynamic 3D shaders to render precisely behind or inside HTML frames without instantiating multiple performance-heavy WebGL contexts.
* **Polymorphic `<MediaFrame>` Primitive:** Replace generic `img`/`video` tags with a smart asset component. It handles progressive media rendering: starting with a tiny inline SVG trace, upgrading to a dynamically loaded WebP/AVIF, and escalating to a WebGL texture or inline HLS video stream based on client hardware capabilities and network conditions, isolated behind a React Suspense boundary.
* **Compound Case-Study Layout System (`<CaseStudy.*>`):** Build a flexible, typed component system (`<CaseStudy.Hero>`, `<CaseStudy.EditorialSplit>`, `<CaseStudy.AspectStack>`, `<CaseStudy.Footnote>`). Each block automatically injects scoped CSS container queries and local custom properties (`--loam-surface`, `--loam-accent`), allowing individual showcase modules to flip color themes (e.g., Alabaster to Obsidian) and cursor states dynamically as the user scrolls through a project page.
* **Viewport-Triggered Hydration Boundary (`<LazyInteraction>`):** To keep initial JS execution low despite complex animations, wrap interactive components (such as 3D canvas controllers, audio visualizers, or custom color-grading tools) in an intersection-based hydration wrapper. This defers script execution and heavy library parsing until the element is within 200px of entering the viewport.
