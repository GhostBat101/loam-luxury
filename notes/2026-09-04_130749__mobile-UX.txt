Research & Planning Note: Mobile UX for Loam Luxury

Mobile luxury sites usually fall into two traps: generic responsive stacked grids that gut the editorial identity, or heavy, laggy desktop-ported canvases. Drawing from Framer Gallery’s smooth gesture-driven components and Brutalist Websites' uncompromised visual density, Loam Luxury’s mobile experience needs to feel like a tactile, high-weight print object optimized for one-handed navigation.

Key Mobile UX Directives:

- Bottom-Sheet Teardown Drawer: Instead of opening a new page to read a creative site's critique, mobile users trigger an expandable bottom sheet. Pulling up from the bottom third overlays a matte, semi-opaque dark pane containing design analysis, type specs, and tech stack details over the live visual showcase without stripping context or losing scroll depth.
- Tap-and-Hold "X-Ray" View: Borrowing brutalism's directness, screenshots stretch full-bleed to the glass edge without padding. Chrome and typographic overlays fade out on tap-and-hold, clearing the screen entirely so users can scrutinize interface details, textures, and grid alignments.
- Thumb-Zone Deck Selector: Replace the top-corner hamburger menu with an anchored, bottom-right gesture dial. Swiping horizontally through the dial cycles categories (e.g., "WebGL & Canvas," "E-Commerce Luxury," "Micro-Sites") with subtle Web Vibration API haptic ticks at each snap point, mimicking the tactile feedback of a physical lens or swatch ring.
- Darkroom Asset Staging: To prevent layout shifts and keep image loading feeling intentional, unrendered images display as warm-toned, low-contrast silhouette blocks that fade up like darkroom prints as high-res WebP assets complete loading.
