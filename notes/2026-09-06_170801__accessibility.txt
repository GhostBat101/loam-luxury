2024-05-18 | Loam Luxury — Accessibility (a11y) Strategy & Implementation Note

* Radical Contrast as a Luxury Aesthetic: Brutalist Websites proves that high contrast and raw semantic structures carry distinct visual weight. Rather than hiding accessibility behind low-contrast gray typography commonly mistaken for "luxury minimalism," Loam Luxury will enforce a baseline 7:1 contrast ratio for all editorial copy. Focused interactive elements will not use muted browser defaults or suppressed rings; focus states will trigger an intentional 3px solid accent border that acts as a primary graphic detail, turning focus management into a visual design signature.

* Taming Framer-Style Motion for Reduced Motion Rules: Taking cues from Framer Gallery's heavy use of canvas-driven micro-interactions, scroll-bound parallax, and interactive site previews, we must build explicit motion fallbacks. When `prefers-reduced-motion: reduce` is detected, all dynamic card-stacking and spatial tilt effects convert immediately to a clean, static grid. Gallery filter transitions will swap instantly without fade-and-slide sequences, relying on `aria-live="polite"` regions to announce newly visible showcase items to screen readers without triggering layout shifts.

* Accessible Alt-State for Visual Showcases: Because Loam Luxury highlights visually complex sites, image alt text cannot be generic descriptions like "screenshot of website." Every featured site showcase card will include structured, screen-reader-accessible metadata containing three explicit data points: primary visual style (e.g., "Monochrome typography with horizontal scroll"), technical framework used, and a summary of interactive features.

* Pointer-Independent Gallery Navigation: To prevent mouse-centric cursor effects from locking out switch controls or keyboard users, custom cursors will automatically disable whenever keyboard focus is detected. Gallery carousels will support standardized arrow key navigation (`ArrowLeft`/`ArrowRight`) with ARIA roles (`role="region"`, `aria-roledescription="carousel"`), ensuring keyboard focus order strictly mirrors the visual layout.
